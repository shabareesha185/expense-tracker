# 💰 Expense Tracker

A simple and responsive **Expense Tracker Web App** built using **HTML**, **Tailwind CSS**, and **JavaScript**.  
It helps you record your daily expenses, view history, calculate the total amount spent, and clear all records — all stored locally in your browser.

---

## 🚀 Features

✅ Add new expenses with name and amount  
✅ Automatically calculate and display total spending  
✅ View and manage expense history  
✅ Delete individual expenses or clear all history  
✅ Saves data using **LocalStorage** — no backend needed  
✅ Clean, minimal, and responsive UI

---

## 🛠️ Tech Stack

- **HTML5**
- **Tailwind CSS**
- **JavaScript (ES6)**
- **LocalStorage API**

---

## 💾 How to Use

1. Clone the repository  
   ```bash
   git clone https://github.com/your-username/expense-tracker.git
   ```
2. Navigate to the project folder  
   ```bash
   cd expense-tracker
   ```
3. Open the `index.html` file in your browser  
4. Start adding and managing your expenses!
